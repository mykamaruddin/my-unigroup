Here are the codes to download and install the scripts:

1: install_unigroup.sh
sudo curl -o install_unigroup.sh https://raw.githubusercontent.com/mykamaruddin/my-unigroup/refs/heads/myk/install_unigroup.sh
sudo chmod +x install_unigroup.sh
sudo ./install_unigroup.sh
